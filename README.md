## 🛠️ Local Development Setup

This project is built with **Next.js** (App Router). To run the application locally:

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install

2. Open the app:
   Navigate to http://localhost:3000 in your browser. You can start editing the main interface in app/page.tsx.
